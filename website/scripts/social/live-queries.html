Live queries

Syntax

A query is a value.

Build it once. Run it live. The same value works as a one-shot, a subscription, or a read of the past.

01 Declare 
const open = Query.from(Todo)
  .where({ done: false })
  .select({ id: Todo.id, title: Todo.title })
  .orderBy(Todo.createdAt, "asc");
02 Run live 
const { data } = useLiveQuery(db, open);

Stages

.where({ field })

Equality filters, typechecked from the entity

.select({ … })

.orderBy(A, "asc")

.limit(n) · .one()
